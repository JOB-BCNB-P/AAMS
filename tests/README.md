# ชุดทดสอบของ AAMS

รันทั้งหมดจากโฟลเดอร์นี้ (ต้องมี Node.js)

```
node test_subject.js          รายวิชาที่เปิดสอน · รหัสวิชาศูนย์นำหน้า
node test_subjtype.js         ประเภทรายวิชา 4 แบบ และการผูกกับติดตาม/ประเมิน
node test_practicum.js        ข้อมูลแหล่งฝึกภาคปฏิบัติ และการ์ดหน้าหลัก
node test_stuwl.js            ภาระงานนักศึกษา · เข้าระบบด้วยอีเมล · ปิดบังเลขบัตร
node test_evalrpt.js          รายงานผลประเมินรายอาจารย์/แหล่งฝึก · PDF (ตรวจซอร์ส)
node test_evalrpt_render.js   รายงานผลประเมิน · วาดหน้าจริงด้วยข้อมูลปลอม
```

`test_evalrpt.js` มีข้อหนึ่งที่ตรวจว่าไอคอน `data-lucide` ทุกชื่อในระบบ
มีอยู่จริงใน lucide 0.263.0 (รุ่นที่ index.html โหลด) ข้อนี้ทำงานเมื่อ
ติดตั้งแพ็กเกจไว้แล้วเท่านั้น

```
npm install --no-save lucide@0.263.0
```

ถ้าไม่ได้ติดตั้ง ข้อนั้นจะข้ามไปเฉย ๆ ไม่ถือว่าไม่ผ่าน
